Uma história de bem

Desenvolvedor Front-End com 2 anos de experiência prática e mais de 10 anos em suporte técnico em multinacional, com foco em automação bancária e suporte corporativo. Essa trajetória me proporcionou habilidades valiosas em resolução de problemas, gestão de tempo, comunicação clara e trabalho em equipe eficaz — aplicadas hoje no desenvolvimento de soluções digitais.

Formado em Sistemas de Informação e atualmente em formação Full Stack pelo DevClub, atuo na construção de sistemas modernos, rápidos e seguros, com foco em performance, UX/UI e SEO. Trabalho com tecnologias como JavaScript, TypeScript, React, Node.js, MongoDB, Git/GitHub, AWS e Azure.

Um dos meus principais projetos é o DevBurguer – Sistema Completo de Lanchonete Digital, uma aplicação full-stack com alto desempenho e segurança robusta. O sistema utiliza autenticação via JWT, totalização automática de pedidos, painel administrativo intuitivo e integração de pagamentos em tempo real via Stripe.

Além das habilidades técnicas, destaco minha inteligência emocional, comunicação eficiente e capacidade de manter o foco sob pressão — qualidades essenciais em ambientes desafiadores e colaborativos.

O objetivo deste projeto é desenvolver um site conversor de moedas. Nele, o usuário insere o valor em uma moeda e escolhe a moeda de destino para obter a conversão. Esse projeto é uma ótima maneira de entender como criar um conversor de moedas básico.

Projeto Jokenpô

Text To Voice

O Conversor de Texto para Voz é uma aplicação web que permite ao usuário digitar ou enviar um texto, selecionar uma voz e ouvir a leitura desse texto. O objetivo é facilitar a conversão de texto escrito em áudio, tornando o conteúdo mais acessível para pessoas com deficiência visual ou para quem prefere consumir informações de forma auditiva.

DevSorteio

O objetivo deste projeto é desenvolver um site de sorteio aleatório. DevSorteio é um site simples que permite sortear números dentro de um intervalo definido pelo usuário. Com uma interface intuitiva, o site possibilita a escolha de um número aleatório entre dois valores, tornando-o ideal para sorteios rápidos e tomadas de decisão.

Gerador de Senhas

O Gerador de Senhas é uma ferramenta online que permite aos usuários criar senhas fortes e seguras de forma rápida e fácil. Este projeto foi desenvolvido para ajudar a manter a segurança das contas online, gerando senhas únicas e aleatórias.

Cadastro de Usuário

Este projeto é a interface de front-end para uma aplicação de gerenciamento de usuários. Com ele, é possível cadastrar novos usuários e listar usuários existentes através de uma interface web amigável. O projeto se conecta a uma API RESTful, desenvolvida utilizando Node.js, Express, Cors e Prisma, e utiliza o MongoDB como banco de dados.
