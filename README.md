## Projeto Principal — DevBurguer

Sistema completo de lanchonete digital — do pedido ao pagamento, em produção.

**O que foi construído:**
- Autenticação JWT com dois perfis distintos (Cliente e Admin) + Bcrypt
- Integração de pagamentos via Stripe com `PaymentIntent` e webhooks
- Gerenciamento de estado global do carrinho com Context API
- Painel Admin otimizado: **fluxo reduzido de 6 para 3 telas** sem perder funcionalidade
- LCP abaixo de **1.2s** com lazy loading, code splitting e otimização de assets

**Stack:** React · Styled Components · Context API · Node.js · Express · PostgreSQL · Sequelize · Stripe · JWT

## Especialidades

**Product Thinking** — Analiso o problema antes de codar. Features orientadas a métrica, não só a requisito. Mapeio jornada do usuário, arquitetura da informação e critérios de sucesso mensuráveis antes de abrir o editor.

**Frontend Engineering** — React + TypeScript com performance e acessibilidade como padrão. Core Web Vitals (LCP, CLS, FID), SEO técnico com Schema.org e componentização estratégica para código que escala.

**Backend & Architecture** — APIs RESTful com Node.js, autenticação segura por perfil com JWT, integração de pagamentos em produção com Stripe e modelagem de dados orientada a performance com MongoDB e PostgreSQL.

## O Diferencial

10 anos em TI corporativa formaram algo que não se aprende só codando:

- **Comunicação técnica clara** — traduz decisões de arquitetura em impacto de negócio
- **Entrega sob pressão real** — histórico em ambientes críticos com tolerância zero a falhas
- **Visão de produto** — cada trade-off técnico passa pelo filtro da experiência do usuário final
- **Responsabilidade com produção** — mentalidade de quem sabe o que significa um sistema fora do ar
